# CyberSentinel

## Core Idea
A **multi-layer URL risk detection system** designed to protects users from phishing attacks and online scams in real time. 

The application is designed to both identify risky websites and educates users about online threats, by providing the phishing features that provided URL contains. 

## Key Features
1. Real-Time Website Risk Detection - Scans URLs using threat intelligence APIs and Machine Learning Model to detect scams and 
phishing. 
2. In-App Risk Notifications (Color-coded) - Clearly alerts users with green (safe), orange (caution), or red 
(danger) indicators. 
3. Educational Follow-Ups for Risk Alerts - Provides detected features when a risk is detected. 
4. Ethical Design - No browsing history tracking; uses secure, privacy-conscious 
APIs.
