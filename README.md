# CyberSentinel Bot

## Core Idea
An Al-powered chatbot + URL risk detection system 
designed to protects users from phishing attacks and online scams in 
real time. The chatbot not only identifies risky websites but also 
educates users about online threats, providing support in English and 
Myanmar(optional feature).

## Key Features 
1. Al Chatbot for Cyber Awareness - Answers cybersecurity-related questions in simple language 
2. Real-Time Website Risk Detection - Scans URLs using threat intelligence APIs to detect scams and 
phishing. 
3. In-App Risk Notifications (Color-coded) - Clearly alerts users with green (safe), orange (caution), or red 
(danger) indicators. 
4. Educational Follow-Ups for Risk Alerts - Provides learning tips when a risk is detected. 
5. Ethical Design - No browsing history tracking; uses secure, privacy-conscious 
APIs. 
6. Myanmar Language Support (optional) - Answers and alerts in Myanmar language for broader reach
